Register a new device slot or deploy an OTA firmware update to an existing fleet device.

Must be a valid compiled ESP32 firmware image (starts with magic byte 0xE9, max 4MB).
Leave blank: Generates a cryptographically random 256-bit API key and registers a brand new device at Version 1.
Provide key: Pushes an update for an existing device, incrementing its version number.
Zero-Knowledge Architecture: Each device slot is secured exclusively by its 64-hex API key. No user accounts or database exist on this server. Only clients presenting the matching key can download the firmware.
